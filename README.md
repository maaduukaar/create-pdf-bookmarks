# 📚 Create PDF Bookmarks

Автоматическое создание закладок (bookmarks) в PDF файлах на основе визуального оглавления.

**Просто укажи страницы с оглавлением** — и скрипт сам извлечёт заголовки, определит уровни вложенности по отступам и создаст структурированные закладки с **точными переходами к заголовкам**!

## 🎯 Основные возможности

### 🚀 Режим работы с PDF (рекомендуется)

- ✅ **Укажи страницы с оглавлением** — просто введи номера страниц (`2` или `2,3` или `2-5`)
- ✅ **Умное определение уровней** — автоматический анализ отступов (X-координат) для вложенности
- ✅ **Точные переходы к заголовкам** — переход не к странице, а прямо к заголовку (новое в v2.1)
- ✅ **Любой формат оглавления** — работает с точками-лидерами, пробелами, с номерами и без
- ✅ **Drag & Drop** — перетащи PDF на `run-toc.bat` и всё!

**Почему PDF лучше?**
- Не зависит от формата DOCX и его особенностей
- Видишь визуально, на какой странице оглавление
- Работает с документами из любого источника
- Точное определение вложенности по визуальным отступам
- Автоматический поиск координат заголовков для точной навигации

### � Режим работы с DOCX (fallback)

Для случаев, когда у тебя только DOCX с классическим оглавлением в формате:
```
1. Раздел ......... 5
1.1 Подраздел ..... 7
```

## 🚀 Быстрый старт

### 🏆 Способ 1: PDF + Drag & Drop (самый простой!)

1. Перетащи PDF файл на `run-toc.bat`
2. Введи номера страниц с оглавлением: `2` (или `2,3` или `2-5`)
3. Готово! Получишь `document_with_bookmarks.pdf`

### ⚡ Способ 2: PDF + командная строка

```bash
# Укажи страницы сразу
python bookmarks.py document.pdf -t 2

# Или несколько страниц
python bookmarks.py document.pdf -t 2,3,5-7

# Интерактивный режим (запросит номера)
python bookmarks.py document.pdf --toc-pages
```

### 📋 Способ 3: DOCX (если PDF недоступен)

```bash
# Drag & Drop DOCX на run.bat
# Или командная строка:
python bookmarks.py document.docx
```

**Требования к DOCX:** содержание должно быть в формате `1. Название ... 5`

## 🚀 Пошаговая инструкция (рекомендуемый метод: PDF)

### Шаг 1: Подготовь PDF файл

1. **Найди или создай PDF с оглавлением**
   - У тебя уже есть PDF документ
   - Открой его и найди страницу с оглавлением (обычно 2-3 страница)
   - Запомни номер страницы или номера (если оглавление на нескольких страницах)

2. **Важно:** Не обязательно, чтобы оглавление было идеальным!
   - Работает с точками-лидерами: `Введение ........ 5`
   - Работает с пробелами: `Введение       5`
   - Работает с номерами разделов: `1.1 Введение 5`
   - Работает даже без номеров — уровень определится по отступу!

### Шаг 2: Установка зависимостей (один раз)

3. **Установи Python** (если не установлен)
   - Скачай с [python.org](https://www.python.org/downloads/)
   - Версия 3.7 или выше

4. **Установи PyMuPDF**
   ```bash
   pip install PyMuPDF
   ```

### Шаг 3: Запуск скрипта

5. **Выбери способ запуска:**

   **🏆 Вариант А: Drag & Drop (рекомендуется)**
   - Перетащи PDF файл на `run-toc.bat`
   - Введи номера страниц с оглавлением: `2` или `2,3` или `2-5`
   - Готово!

   **⚡ Вариант Б: Командная строка (быстро)**
   ```bash
   # Если знаешь номер страницы
   python bookmarks.py "Руководство.pdf" -t 2
   
   # Или несколько страниц
   python bookmarks.py "Руководство.pdf" -t 2,3
   ```

   **📝 Вариант В: Интерактивный режим**
   ```bash
   python bookmarks.py "Руководство.pdf" --toc-pages
   ```
   - Скрипт запросит номера страниц
   - Введи: `2` или `2,3` или `2-5`

### Шаг 4: Проверка результата

6. **Проверь созданные файлы**
   - В папке с PDF появится `Руководство_bookmarks.json` (структура закладок)
   - И главное: `Руководство_with_bookmarks.pdf` — PDF с закладками!

7. **Открой PDF с закладками**
   - Открой файл `*_with_bookmarks.pdf`
   - В PDF Reader (Р7 Офис, Chrome, Adobe, Foxit) открой панель закладок
   - Проверь структуру — уровни должны определиться автоматически по отступам!

### Шаг 5: Если что-то пошло не так

8. **Скрипт не нашёл заголовки?**
   - Проверь номера страниц — возможно оглавление на других страницах
   - Посмотри отладочный вывод — он покажет, какие строки пропущены
   - Попробуй указать смежные страницы: вместо `-t 2` используй `-t 2,3`

9. **Уровни определились неправильно?**
   - Скрипт покажет найденные уровни отступов с X-координатами
   - Если в PDF оглавление не имеет чётких отступов, используй DOCX режим

## 📄 Альтернатива: работа с DOCX (fallback метод)

Если у тебя **нет PDF** или **оглавление в нестандартном формате**, можешь использовать DOCX режим.

### Требования к DOCX

Содержание должно быть в формате:
```
1. НАЗНАЧЕНИЕ ПРОГРАММЫ.......5
1.1 Наименование программы    5
1.2.1 Функции модулей ПК 5
```

### Запуск с DOCX

```bash
# Drag & Drop DOCX на run.bat
# Или командная строка:
python bookmarks.py "Руководство.docx"
```

**Ограничения DOCX режима:**
- Требуется строгий формат: `номер + название + страница`
- Не работает с заголовками без номеров
- Зависит от правильности форматирования DOCX


## � Как работает режим PDF (подробности)

### Алгоритм определения уровней

1. **Извлечение текста с координатами** — скрипт читает указанные страницы PDF и получает точные X-координаты каждой строки
2. **Группировка отступов** — близкие координаты (<5px) группируются в один уровень
3. **Автоопределение вложенности** — чем правее отступ, тем глубже уровень вложенности
4. **Разбор содержимого** — извлекает заголовки и номера страниц независимо от формата
5. **Поиск точных координат** _(новое в v2.1)_ — автоматически находит каждый заголовок в документе и получает его точные координаты для навигации

### Поддерживаемые форматы оглавления в PDF

Скрипт работает с **любыми** форматами оглавления:

```
# С номерами разделов и точками-лидерами
1. Introduction .......... 5
1.1 Background ........... 6
  1.1.1 History .......... 7

# Без номеров (уровень по отступу)
Introduction .......... 5
  Background ........... 6
    History ............ 7

# С пробелами вместо точек
1. Chapter One    10
   Introduction   11
   1.1 Section    12

# Смешанный формат
Getting Started ........ 3
  1. Installation ...... 4
  2. Configuration ..... 7
Advanced Topics ........ 15
```

**Что важно:**
- ✅ Работает с любыми символами между названием и номером страницы
- ✅ Определяет уровень даже без номеров разделов (по визуальному отступу)
- ✅ Игнорирует лишние элементы (линии, таблицы и т.д.)

## 📐 Структура JSON

JSON файл содержит массив корневых закладок. Каждая закладка имеет:

| Поле | Тип | Описание |
|------|-----|----------|
| `title` | string | Название закладки с номером раздела |
| `dest` | array | `[страница, "Fit"]` — навигация к странице |
| `color` | object | RGB цвет: `{"0": 0, "1": 0, "2": 0}` (черный) |
| `bold` | boolean | Жирное начертание (по умолчанию false) |
| `italic` | boolean | Курсивное начертание (по умолчанию false) |
| `children` | array | Массив вложенных закладок |

## 🎨 Настройка закладок

Для изменения внешнего вида закладок отредактируй JSON перед встраиванием:

```json
{
  "title": "1 ВАЖНЫЙ РАЗДЕЛ",
  "dest": [5, "Fit"],
  "color": {"0": 1.0, "1": 0.0, "2": 0.0},  // Красный цвет
  "bold": true,                               // Жирный текст
  "italic": false
}
```

## 🐛 Решение проблем

### Закладки не находятся

**Проблема:** `⚠ Строки содержания не найдены!`

**Решение:**
1. Проверь формат содержания в DOCX
2. Убедись, что строки содержат: номер раздела + текст + номер страницы
3. Пример правильной строки: `1.2.1 Название раздела 15`

### PDF файл не найден

**Проблема:** `⚠ PDF файл с именем 'document.pdf' не найден`

**Решение:**
1. Убедись, что PDF имеет то же имя, что и DOCX
2. Или укажи путь к PDF вручную при запросе
3. Или используй только JSON (без встраивания)

### PyMuPDF не установлен

**Проблема:** `⚠ PyMuPDF не установлен - встраивание закладок недоступно`

**Решение:**
```bash
pip install PyMuPDF
```

### Неправильная кодировка в JSON

**Проблема:** Кириллица отображается как `\uXXXX`

**Решение:** JSON всегда сохраняется с `ensure_ascii=False`, кириллица должна читаться корректно. Открой в редакторе с поддержкой UTF-8.

## 📚 Технические детали

### Алгоритм извлечения

1. Читает все параграфы из DOCX
2. Применяет регулярное выражение: `^(\d+(?:\.\d+)*)\.?\s+(.+?)\s+(\d+)$`
3. Извлекает: номер раздела, название, номер страницы
4. Вычисляет уровень вложенности по количеству точек в номере
5. Строит иерархическое дерево закладок

### Формат destination

Используется формат `[page, "Fit"]`:
- `page` — номер страницы (1-based)
- `"Fit"` — режим отображения (вписать страницу в окно)

Альтернативные форматы:
- `[page, "XYZ", x, y, zoom]` — точное позиционирование
- `[page, "FitH", top]` — по ширине с указанием верхней точки
